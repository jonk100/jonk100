The `TreeView` component transforms a deeply nested JSON-like structure into an interactive folder hierarchy. By using native `<details>` and `<summary>` tags, it provides fully accessible keyboard navigation (using the Space or Enter keys to expand/collapse) without requiring any JavaScript event listeners.

### Usage Blueprints

#### Common: File System Explorer
Using the tree view to represent directories, complex taxonomies, or organizational charts:
