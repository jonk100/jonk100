The `Svg` component is a robust alternative to standard image-based icons. Unlike the `Icon` component (which may load icons from a folder), `Svg` is bound directly to our centralized TypeScript icon registry. This provides developers with full IDE autocomplete for icon names and ensures that every vector on the site is strictly tracked and typed.

## Typed Vector Injection
The core strength of the `Svg` primitive is its deep integration with the TypeScript type system. By importing `SvgName` from our design tokens, the component guarantees that you can never reference an icon that doesn't exist in the registry. At build time, the component fetches the corresponding SVG component and injects it directly into the HTML, ensuring the vector paths are available for CSS styling and hardware-accelerated transitions.

## Usage Blueprints

### Common: Scaled Iconography
Demonstrates how the semantic sizing scale ensures that icons remain perfectly proportioned relative to the surrounding typography:

<ComponentPreview
  title="Semantic Vector Scaling"
>

    <Svg name="badge" size="sm" />
    <Svg name="badge-group" size="md" />
    <Svg name="bento-grid" size="lg" />
    <Svg name="box" size="xl" stroke="var(--accent)" />
  </Inline>
</ComponentPreview>
