The `KeyValueList` component provides a structured, responsive grid layout for displaying key-value pairs. It leverages CSS Grid with `display: contents` to maintain definition list semantics (`<dl>`, `<dt>`, `<dd>`) while enforcing a rigid horizontal alignment.

### Usage Blueprints

#### Common: Standard Metadata Display
Use `KeyValueList` for displaying properties, specifications, or metadata ledgers:

<ComponentPreview title="Metadata Properties">
  <div style="width: 100%; max-width: 500px; margin: 0 auto; text-align: left;">
    <KeyValueList 
      title="Environment Variables"
      items={[
        { key: "PORT", value: "8080" },
        { key: "NODE_ENV", value: "production" },
        { key: "DB_HOST", value: "localhost" }
      ]}
    />
  </div>
</ComponentPreview>
