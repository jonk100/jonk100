The `Badge` component is a lightweight typographic indicator used for tags, status labels, and count markers. Standardizing this primitive allows us to manage complex thematic transparencies and ensure that small-scale text remains legible against varied background surfaces.

### RGB Transparency Architecture
To achieve the "glassy" semi-transparent backgrounds characteristic of modern UI without hardcoding hundreds of hex values, we utilize RGB design tokens. By mapping theme colors to `--primary-rgb` and similar variables, the component can dynamically generate alpha-blended backgrounds:
```css
.badge--primary {
  background: rgba(var(--primary-rgb), 0.15);
  color: var(--primary);
  border-color: rgba(var(--primary-rgb), 0.3);
}
```
This approach ensures that badges naturally "soak up" the color of the underlying surface, maintaining a cohesive aesthetic regardless of the elevation layer they are placed upon.

### Compound Component: BadgeGroup
The `BadgeGroup` component attaches multiple badges into a single segmented pill. It is frequently used for combined status readouts, such as version numbers or build results, where the relationship between the pieces of data needs to be visually explicit.
