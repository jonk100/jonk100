The `Multiselect` component is a complex, interactive form control that combines a searchable text input with a multi-selection dropdown list. Chosen options are dynamically rendered as dismissible chips directly within the input field.

### Native Form Fallback
While the UI is entirely custom and JavaScript-driven, the component maintains a hidden `<select multiple>` element in the DOM. The controller synchronizes the chip state with this hidden select, ensuring that the component functions perfectly during standard HTML form submissions.

### Usage Blueprints

#### Common: Category Tagging
A standard implementation for assigning multiple categories or tags to an item:

<ComponentPreview title="Searchable Multiselect">
  <div style="width: 100%; max-width: 400px; margin: 0 auto;">
    <Multiselect 
      label="Select Genres"
      placeholder="Filter options..."
      initialSelected={['satire', 'spy']}
      options={[
        { label: 'Political Satire', value: 'satire' },
        { label: 'Spy Thriller', value: 'spy' },
        { label: 'Black Comedy', value: 'comedy' },
        { label: 'Period Drama', value: 'period' },
        { label: 'Dark Farce', value: 'farce' },
        { label: 'Psychological', value: 'psych' },
        { label: 'Historical Fiction', value: 'historical' }
      ]}
    />
  </div>
</ComponentPreview>
