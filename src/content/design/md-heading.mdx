The `MdHeading` component is designed to solve common issues in long-form technical reading. While standard headings are static, `MdHeading` provides interactive features like automatic anchor links and sticky positioning to help users maintain context as they navigate through dense documentation.

### Stickiness & Contextual Blur
When the `sticky` prop is enabled, the heading uses `position: sticky` aligned with the global header offset. To ensure content doesn't abruptly disappear behind the header, we apply a `backdrop-filter: blur(8px)` and a linear gradient mask. This creates a professional "glass" effect where content softly fades out as it scrolls under the sticky section title.

### Usage Blueprints

#### Common: Interactive Header List
Standard headings automatically reveal an anchor link on hover, allowing users to copy deep links directly to specific sections:

<ComponentPreview
  title="Anchor Link Reveal"
>
  <div style="width: 100%; max-width: 500px; margin: 0 auto; text-align: left;">
    <MdHeading level={3} id="arch-overview">Architectural Overview</MdHeading>
    <Text type="body-sm">Hover over the heading above to reveal the deep-link anchor (#).</Text>
  </div>
</ComponentPreview>
