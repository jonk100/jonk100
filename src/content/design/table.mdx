The `Table` component family provides a robust way to render complex data sets while maintaining strict semantic HTML standards. It abstracts the boilerplate of standard `<table>` markup into a series of composable Astro components that handle consistent padding, alignment, and hover interactions.

## Responsive Data Wrappers
Tabular data is notoriously difficult to handle on small screens. The `Table` component includes a built-in `table-wrapper` that enables horizontal scrolling (`overflow-x: auto`) when the table width exceeds its parent container. This ensures that your structured data remains accessible on mobile devices without breaking the broader page layout.
