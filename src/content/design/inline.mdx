The `Inline` component is our core horizontal layout primitive, extending standard HTML dynamic tags (such as `<div>`, `<ul>`, or `<ol>`) through the `as` parameter. Standardizing this component eliminates the fragile practice of applying right or left margins on list items. This ensures that horizontal elements (like tags, badges, or buttons) wrap naturally and align consistently across responsive viewports without leaking styles.

### The Problem with Sideways Margins
Traditional CSS layouts often manage horizontal spacing by applying `margin-right` to children, requiring complex `:last-child` overrides to prevent extra white space at the container's edge. 

`Inline` completely sidesteps this by wrapping elements inside a modern CSS flex layout utilizing the standard `gap` property. This automates gutters only between siblings and respects flex boundaries, resulting in fluid spacing that perfectly accommodates varying screen widths.

### Usage Blueprints

#### Common: Wrapping Tag Cloud
Instead of hardcoding item offsets that cause layout breaks on small mobile viewports, you can wrap them in an `Inline` container. This handles horizontal gaps and line wrapping automatically:

<ComponentPreview
  title="Wrapping Tag Cloud"
>
  <div style="width: 100%; max-width: 320px; margin: 0 auto;">
    <Inline gap="xs" wrap={true}>
      <Badge theme="primary">Development</Badge>
      <Badge theme="secondary">Creative</Badge>
      <Badge theme="accent">Cinematography</Badge>
      <Badge theme="ghost" outlined>Blueprints</Badge>
    </Inline>
  </div>
</ComponentPreview>
