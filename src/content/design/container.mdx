The `Container` component is a high-level layout primitive used to group related elements into distinct visual blocks. While `Box` is for atomic spacing, `Container` is designed for structural sections, defaulting to a vertical flex-stacking behavior that ensures children are evenly spaced and aligned.

### Layout Framing & Matte Logic
To support varied aesthetic styles across the portfolio—ranging from "clean" minimal designs to "glassmorphic" cyberpunk layouts—the `Container` integrates our global framing system. By passing `frame="glass"`, the component dynamically layers translucent backgrounds and backdrop filters, allowing you to create complex, multi-layered interfaces by simply nesting containers with different frame variants.

### Usage Blueprints

#### Common: Content Segmentation
Use containers to wrap distinct sections of information, such as card headers or feature lists:

<ComponentPreview
  title="Standard Section Container"
>
  <div style="width: 100%; max-width: 400px; margin: 0 auto;">
    <Container class="default" style="border-radius: var(--rad-md); border: 1px solid var(--border-subtle);">
      <Badge theme="accent" size="xs">System Alert</Badge>
      <Text type="h4" style="margin: 0;">Update Synchronized</Text>
      <Text type="body-sm" tone="subtle">All remote registry blueprints have been successfully applied to the local architecture.</Text>
    </Container>
  </div>
</ComponentPreview>

#### Advanced: Glassmorphic Panel Composition
Demonstrates how to utilize the `effects` and `frame` props to build high-fidelity interface panels that leverage modern browser backdrop filters:
