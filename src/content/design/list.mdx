The `List` component is a targeted layout wrapper for unordered, ordered, and description lists. Browsers enforce unpredictable default paddings and margins on `<ul>` and `<ol>` nodes, leading to misaligned text blocks. This primitive resets those defaults, binds bullet spacing to our global tokens, and controls the internal vertical rhythms.

### Global Sibling Penetration
Rather than requiring developers to import and wrap every single bullet point inside a custom `<ListItem>` component, `List` uses CSS `:global` selectors inside its scoped stylesheet to automatically manage descendants:
```css
.list.gap-sm :global(li:not(:last-child)) { 
  margin-bottom: var(--space-2); 
}
```
This architectural decision drastically reduces component boilerplate in templates. It allows developers to write standard semantic `<li>` or `<dt>` elements inside the list block while guaranteeing that spacing correctly maps to the requested `gap` property.
