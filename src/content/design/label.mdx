The `Label` component is a powerful compositional wrapper. Unlike the `Input` component (which is a monolithic wrapper around a text field), `Label` allows you to wrap *any* form control—like a custom `Multiselect` or `RangeSlider`—while automatically providing standardized labels, helper text, and error states.

### CSS :has() Selector Magic
When an `error` prop is passed, the `Label` component utilizes the modern CSS `:has()` pseudo-class to style its children.
```css
.label-group:has(.error-text) :global(.form-input) {
  border-color: var(--text-danger);
}
```
This means the `Label` can automatically turn the border of a slotted input red without needing to pass an error prop down into the child component itself.

### Usage Blueprints

#### Common: Form Field Composition
Using the label to wrap a standard input and provide context:

<ComponentPreview title="Form Label with Helpers">
  <div style="width: 100%; max-width: 400px; margin: 0 auto; text-align: left;">
    <Stack gap="lg">
      <Label for="demo-title" label="Episode title" required={true} helperText="Used in credits, slug, and series bible.">
        <input class="control variant--default control--md" style="width:100%" id="demo-title" placeholder="e.g. The Long Game" />
      </Label>
      
      <Label for="demo-logline" label="Logline" optional={true} helperText="Appears on the pitch deck overview page.">
        <input class="control variant--default control--md" style="width:100%" id="demo-logline" placeholder="One-sentence premise" />
      </Label>
    </Stack>
  </div>
</ComponentPreview>

Demonstrates how passing an error string overrides the helper text and applies error styling:
