The `Code` primitive acts as a unified typographic wrapper for rendering technical snippets and syntax displays. Standard HTML `<code>` and `<pre>` elements lack aesthetic formatting and syntax parsing. By standardizing this component, we establish a global monospace typography baseline and provide integrated capabilities for framing, captioning, and parsing syntax using Astro's built-in Shiki highlighter.

### Component-Level Highlighting Delegation
The architecture of this component conditionally delegates rendering payloads. If `inline={true}`, it outputs a lightweight, padded `<code>` node tailored for embedding within prose sentences. However, if rendering a block, it leverages Astro's `<Code>` component directly. This allows us to statically generate rich, tokenized HTML syntax coloring at build time without shipping massive client-side javascript libraries to the user's browser.

### Usage Blueprints

#### Common: Inline and Standard Blocks
Combine the inline text snippets with standard block configurations to display technical references within articles:

<ComponentPreview
  title="Code Snippet States"
>
  <div style="width: 100%; max-width: 500px; margin: 0 auto; text-align: left;">
    <Stack gap="md">
      <Text type="body">
        To initialize the sequence, you must call the <Code inline={true}>initSequence()</Code> method on the class instance.
      </Text>
      <Code 
        inline={false} 
        language="javascript" 
        code={`function initSequence() {\n  console.log("Sequence started.");\n  return true;\n}`}
      />
    </Stack>
  </div>
</ComponentPreview>
