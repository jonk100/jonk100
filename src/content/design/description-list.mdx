The `DescriptionList` component is similar to `KeyValueList` but utilizes a vertical stacking layout by wrapping pairs in grouped `<div>` elements. It is ideal for displaying longer descriptions or glossary terms where a strict horizontal split is insufficient.

### Usage Blueprints

#### Common: Glossary Terms
A standard implementation for defining concepts or providing detailed specs:

<ComponentPreview title="Glossary Definitions">
  <div style="width: 100%; max-width: 500px; margin: 0 auto; text-align: left;">
    <DescriptionList 
      title="Terminology"
      items={[
        { term: "Abstract Syntax Tree (AST)", description: "A tree representation of the abstract syntactic structure of source code." },
        { term: "Lexical Analysis", description: "The process of converting a sequence of characters into a sequence of tokens." }
      ]}
    />
  </div>
</ComponentPreview>
