The `Checkbox` component coordinates native form multi-selection logic with custom visual layouts, wrapping the standard HTML `<input type="checkbox">` element. Because native browser checkboxes suffer from inconsistent visual formatting and cannot load custom check icons, standardizing this component lets us build high-contrast bounding boxes, support custom color themes, and animate vector checkmark grids.

### Visual Bridging & Scaled Transitions
To achieve a high-fidelity visual experience without sacrificing access standards, we utilize a sibling checkbox mapping system:
1. **Accessibility Containment**: The native checkbox input is visually hidden using the global `.sr-only` class. This preserves standard browser focus rings and keyboard Tab navigation sequence lists.
2. **Visual Box Binding**: We construct a visual `.checkbox-box` sibling container housing a nested `<Icon name="check" />`.
3. **Pulsing Tick Scale**: When selected, the hidden input triggers sibling selectors to scale and animate the checkmark:
   ```css
   .checkbox-input:checked + .checkbox-box .checkbox-icon {
     opacity: 1;
     transform: scale(1);
   }
   ```
   This hardware-accelerated transition provides instant, fluid visual feedback when clicked.
