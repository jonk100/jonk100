The `ToggleButton` is a semantic button primitive designed specifically for on/off states. Unlike a standard button, it relies on the `aria-pressed` attribute to communicate its state to screen readers and to trigger CSS styling changes.

### Uncontrolled State Management
By default, the component includes a lightweight inline `onclick` handler that automatically toggles the `aria-pressed` attribute. This allows it to function as an uncontrolled component out of the box, requiring zero external JavaScript for visual state updates.

### Usage Blueprints

#### Common: Text Formatting Toolbar
A classic use case for toggle buttons is a rich text editor toolbar:
