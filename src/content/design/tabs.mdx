The `Tabs` component allows for rapid switching between related content blocks without changing the page URL. It is particularly effective for technical documentation, where users may want to toggle between different code languages or between a visual preview and its source code.

## Web Component State Management
To avoid the overhead of heavy frameworks while maintaining a responsive user interface, the `Tabs` suite is powered by a Vanilla TypeScript custom element: `<tabs-controller>`. 
1. **Zero-Framework Reactivity**: The controller manages `aria-selected` and `data-state` attributes internally, using native DOM APIs to toggle visibility.
2. **Keyboard Accessibility**: The controller implements the standard WAI-ARIA tab pattern, supporting `ArrowRight` and `ArrowLeft` keys for rapid navigation through the list.
3. **Hardware Acceleration**: Tab transitions utilize CSS transforms and opacity, offloading panel entrance motions to the browser's GPU.

## Usage Blueprints

### Common: Content Categorization
Group standard data blocks into labeled tabs to save vertical screen real estate:

<ComponentPreview
  title="Standard Content Tabs"
>
  <Tabs defaultTab="overview">
    <div slot="tabs">
      <TabButton target="overview">Overview</TabButton>
      <TabButton target="specs">Technical Specs</TabButton>
      <TabButton target="docs">Reference</TabButton>
    </div>
    
    <TabPanel id="overview">
      <Box padding="md" layer={1} radius="md">
        <Text type="h3">Project Overview</Text>
        <Text type="body-sm">The primary monolithic services required for operational logic. These systems must be initialized before booting the interface layer.</Text>
      </Box>
    </TabPanel>
    
    <TabPanel id="specs">
      <Box padding="md" layer={1} radius="md">
        <Text type="h3">System Architecture</Text>
        <Text type="body-sm" style="font-family: var(--mono);">node_env: production<br />latency: 12ms</Text>
      </Box>
    </TabPanel>

    <TabPanel id="docs">
      <Box padding="md" layer={1} radius="md">
         <Text type="body-sm">Documentation and API references are generated dynamically from the source registry.</Text>
      </Box>
    </TabPanel>
  </Tabs>
</ComponentPreview>
