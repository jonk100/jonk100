While the standard `Input` component handles generic text entry, specialized interactive patterns like searching and auto-completion require additional visual cues and interaction logic. We provide `Search` and `ComboBox` as first-class primitives to standardize these patterns across the platform.

### Native Power & Vector Alignment
Both components leverage native browser capabilities to ensure high performance and accessibility:
1. **Search Reset Semantics**: The `Search` component utilizes `type="search"`. This triggers native browser behaviors, such as the OS-specific "clear" button, while our scoped CSS ensures the icon remains hardware-aligned.
2. **Datalist Suggestion Engine**: The `ComboBox` uses a native HTML `<datalist>`. This allows for high-performance filtering of thousands of options directly in the browser's UI thread.
