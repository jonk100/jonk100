The `Frame` component is a layout primitive designed to display images and media assets cropped to precise geometric aspect ratios. By extending a standard HTML `<div>` wrapper around a native image, we establish standard aspect-ratio proportions. We built this component specifically to standardize aesthetic dimensions and eliminate browser layout shifts (CLS) when images load asynchronously.

### Usage Blueprints

#### Common: Core Geometric Shapes
Instead of applying manual CSS crop parameters to every picture on your site, you can pass a `shape` prop. This consolidates standard aspect ratios into a single visual catalog grid:

#### Advanced: Scale-Neutral Grayscale Filter Transitions
For design systems seeking high-fidelity animations, `Frame` allows custom class and style overrides. Here we demonstrate how to combine a round aspect ratio (`shape="circle"`) with a layout-neutral grayscale-to-color transition.

By animating the nested image with `transform` on hover, we trigger high-performance GPU rendering without causing page reflows or resizing the parent container boundaries:

<ComponentPreview
  title="Hardware-Accelerated Grayscale Circle"
>

      style="width: 120px; height: 120px; transition: transform 0.3s cubic-bezier(0.16, 1, 0.3, 1);"

  </div>
