The `Stack` component is our core vertical layout primitive, extending standard HTML dynamic tags (like `<div>`, `<section>`, or `<article>`) through the `as` parameter. Standardizing this component eliminates the need to hardcode arbitrary top/bottom margins on child content blocks. This separates visual layout guidelines from content elements, ensuring that vertical gutters flow uniformly across all page lists.

### The Lobotomized Owl Selector
To automate sibling gutters without polluting the styles of individual children, `Stack` utilizes the legendary **lobotomized owl selector** (`* + *`) inside its stylesheet:
```css
.stack > * + * {
  margin-top: var(--gap);
}
```
This selector targets only elements that are preceded by another sibling inside the container. This eliminates the need for manual margin-top resets on first-child elements or padding trims on last-child containers, keeping page rendering highly modular and performant.

### Usage Blueprints

#### Common: Stacking Content Lists
Instead of applying manual margin rules to every card in your column, you can wrap them in a `Stack` block. This consolidates vertical spacing gaps into a single layout controller:

<ComponentPreview
  title="Vertical Gutters Column"
>
  <Stack gap="sm" style="width: 100%; max-width: 320px; margin: 0 auto;">
    <Paper layer="1" padding="xs"><Text style="margin:0; text-align: center; font-size:var(--text-xs);">Stacked Item A</Text></Paper>
    <Paper layer="1" padding="xs"><Text style="margin:0; text-align: center; font-size:var(--text-xs);">Stacked Item B</Text></Paper>
    <Paper layer="1" padding="xs"><Text style="margin:0; text-align: center; font-size:var(--text-xs);">Stacked Item C</Text></Paper>
  </Stack>
</ComponentPreview>
