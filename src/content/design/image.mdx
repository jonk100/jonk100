The `Image` primitive extends the native HTML `<img>` tag to provide a robust, high-performance visual asset container. Standardizing this component ensures visual consistency and gives us a system-wide baseline to handle loading shimmers, image aspect cropping, caption positioning, and interactive lightboxes out of the box.

### Architectural Decisions
To guarantee a resilient user interface, we implemented two key systems:
1. **Fallback Scripting**: We attach a lightweight client-side `onerror` handler directly to the element. If the primary asset fails to load (e.g., due to a broken path or network timeout), the script intercepts the event and dynamically swaps the raw source to the `fallbackSrc` without throwing console exceptions.
2. **Native Dialog Lightbox**: The click-to-zoom feature leverages the high-performance browser-native `<dialog>` element. Rerouting fullscreen zooming through `<dialog>` avoids complex z-index stack positioning wars and renders the modal in the browser's high-priority top layer.

### Usage Blueprints

#### Common: Default Loaders & Fallback Recovery
Rather than managing broken images with manual javascript event bounds, the component provides loading shimmers and automatic failure fallbacks:

#### Advanced: Polaroid Frame & Translucent Caption Overlay
In design layouts where imagery needs specialized presentation, you can activate the polaroid layout. This wraps the image in a high-contrast container matte and supports a floating, translucent caption overlay (`captionPosition="o-bottom"`). 

Additionally, clicking the image triggers the interactive lightbox overlay for deep examination:
