The `Chip` component represents a complex piece of information in a compact form, such as an entity (person, place, or thing) or a piece of text. Unlike a static `Tag`, a `Chip` is interactive. It functions as a button, supports selection states, and can be dismissed (removed) by the user.

### ARIA Options
To ensure screen readers understand the interaction model, the `Chip` utilizes `role="option"` and `aria-selected`. When users click the chip, an inline script toggles the `.selected` class and updates the ARIA state automatically.

### Usage Blueprints

#### Common: Filter Selection
Using chips as interactive toggle filters:

<ComponentPreview title="Selectable Filter Chips">
  <div style="width: 100%; display: flex; justify-content: center;" role="group" aria-label="Filter by genre">
    <Inline gap="sm" wrap={true}>
      <Chip label="Drama" />
      <Chip label="Comedy" />
      <Chip label="Satire" selected={true} />
      <Chip label="Spy" selected={true} />
      <Chip label="Historical" />
    </Inline>
  </div>
</ComponentPreview>

#### Advanced: Dismissible Entities
Using chips to represent selected entities that the user can remove:

  <div style="width: 100%; display: flex; justify-content: center;">

    </Inline>

</ComponentPreview>
