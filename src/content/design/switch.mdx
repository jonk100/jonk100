The `Switch` component provides a styled interactive toggle designed to switch between binary states, wrapping a native HTML `<input type="checkbox">` element. Because the standard HTML5 spec lacks a native sliding toggle switch component, standardizing this component allows us to compose custom tracks and sliding thumbs under a single tag while preserving full accessibility hooks.

### Accessibility & Track Animations
To deliver a fluid interaction that remains completely browsable by assistive technologies, we implemented a layered design:
1. **The Visual Hide (`sr-only`)**: The native checkbox remains on the page but is styled with our global `.sr-only` utility. This hides it visually while keeping it fully focusable via standard keyboard Tab sequences.
2. **Semantic Role Declarations**: The input is marked with `role="switch"` and `aria-checked`. This informs screen readers that the checkbox acts as an active toggle switch rather than a standard multiple-choice box.
3. **Sliding CSS Transitions**: When checked, the toggle track scales its HSL background color, and the nested thumb translates rightward:
   ```css
   .switch-input:checked + .switch-track .switch-thumb {
     transform: translateX(1.25rem);
   }
   ```
   This offloads the animation to the browser's GPU transform matrices, ensuring stutter-free sliding transitions.

Instead of manually declaring track parameters for every settings form, you can pass state and label properties. This consolidates standard configurations inside a single visual preview showcase:
