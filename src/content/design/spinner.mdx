The `Spinner` component provides a lightweight, pure-SVG visual cue for ongoing operations. Unlike GIF-based spinners, this SVG implementation remains crisp at any resolution and allows for runtime customization of colors, speeds, and dimensions using CSS variables.

### SVG Stroke Animation
To avoid the need for complex external dependencies, we utilize the native `stroke-dasharray` and `stroke-dashoffset` attributes. The rotating animation is bound to the `svg` container, while the "head" of the spinner is a partial circle stroke. This creates a high-contrast, professional rotation effect that is completely controlled by our global design tokens.
