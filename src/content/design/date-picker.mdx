The `DatePicker` component leverages the powerful, built-in calendar and clock widgets provided by modern mobile and desktop browsers (via `<input type="date">` and `<input type="time">`). Rather than shipping an enormous, slow client-side calendar library, this component relies on the OS-level UI while wrapping the trigger field in our design system's cohesive input styles.

### Usage Blueprints

#### Common: Standard Date and Time Entry
Using the date picker for scheduling features:
