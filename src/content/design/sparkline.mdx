The `Sparkline` component generates a lightweight, inline vector graphic directly from an array of numbers. By calculating the SVG path at compile time (or directly on the server), it avoids the massive bundle size of client-side charting libraries like Chart.js or D3, making it perfect for dashboards and data tables.

### Usage Blueprints

#### Common: Server Load Trends
Using sparklines to display historical metrics within minimal UI cards:

<ComponentPreview title="Minimal Metrics Readout">
  <div style="width: 100%; display: flex; justify-content: center;">
    <Inline gap="xl">
      <Stack gap="2xs" align="start">
        <Text type="label" tone="subtle">CPU Usage</Text>
        <Sparkline data={[12, 14, 18, 45, 80, 65, 40, 20, 25, 30]} strokeColor="var(--text-danger)" />
      </Stack>
      <Stack gap="2xs" align="start">
        <Text type="label" tone="subtle">Memory</Text>
        <Sparkline data={[40, 41, 42, 43, 42, 44, 45, 45, 46, 46]} strokeColor="var(--text-success)" fill={true} />
      </Stack>
    </Inline>
  </div>
</ComponentPreview>
