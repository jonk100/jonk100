The `Paper` component is our foundational surface block, extending the standard HTML `<div>` element. When building a design system, interfaces require clear visual hierarchy. We standardized `Paper` to consolidate surface elevation variables, shadow calculations, border outlines, and container paddings into a single, cohesive modular wrapper.

### The Science of Elevations
To create visual depth, `Paper` maps layers `"-1"` through `"5"` to progressive HSL custom properties. 
- **Recessed Surface (`layer="-1"`)**: Utilizes a darker, slightly desaturated background tone. Perfect for background gutters or layout boards.
- **Base Surface (`layer="0"`)**: Matches the global layout background.
- **Elevated Surfaces (`layer="1"` to `"5"`)**: Progressively mix lighter values into the background HSL properties while scaling box shadows. This creates a realistic visual illusion of components floating closer to the light source, rising above background assets.

### Usage Blueprints

#### Common: Elevation Progression Grid
Instead of manually declaring individual background colors and shadow offsets across your stylesheet, you can simply adjust the `layer` parameter. This consolidates standard elevations into a single visual catalog grid:

#### Advanced: Glowing Hardware-Accelerated Terminal
For high-fidelity status readouts, you can combine dark elevations (`layer="3"`), dynamic glows (`effects="glow"`), and entrance slide-up motions.

Using HSL transparency formulas within shadow offsets allows the glow to scale smoothly. The entrance motion is bound to CSS transform matrices, which offloads rendering to the GPU for high-performance animation frames:
