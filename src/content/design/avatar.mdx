The `Avatar` component is a high-fidelity media primitive designed to represent users or entities. It extends standard image rendering with robust fallback logic and status signaling, ensuring that the interface remains polished even when user-provided assets are broken or missing.

### Resilience and Status Signaling
To provide a seamless experience, we implemented two key architectural features:
1. **Double-Layer Fallback**: The component uses a client-side `onerror` script to detect broken image paths. If an error occurs, the image is hidden and the `avatar-fallback` node (containing initials) is instantly displayed, preventing a broken "missing image" icon from appearing.
2. **Relative Status Positioning**: The status indicator dot is sized as a percentage of the parent container and absolutely positioned at the bottom-right. By using percentage-based dimensions (`width: 25%`), the status dot scales proportionally regardless of whether the avatar is 16px or 80px wide.
