The `Slider` component enhances the native HTML `<input type="range">` with a custom-styled track and thumb. It includes a dynamic filled-track segment and a JavaScript-powered value readout, providing a premium interactive experience while maintaining full native accessibility.

### Usage Blueprints

#### Common: Standard Configuration
A basic slider with a label and default value readout:

<ComponentPreview title="Standard Slider">
  <div style="width: 100%; max-width: 400px; margin: 0 auto;">
    <Slider label="Volume" min={0} max={100} value={72} />
  </div>
</ComponentPreview>

#### Advanced: Fractional Steps and Units
Demonstrates a slider configured for fractional values, appending a custom unit to the readout:

<ComponentPreview title="Fractional Opacity Slider">
  <div style="width: 100%; max-width: 400px; margin: 0 auto;">
    <Slider label="Opacity" min={0} max={1} step={0.01} value={0.45} unit="px" />
  </div>
</ComponentPreview>
