The `Text` component is our primary polymorphic typographic primitive. It replaces the use of raw HTML header and paragraph tags (`<h1>`, `<p>`, `<span>`) across the codebase. By routing all text rendering through a single component, we ensure that font sizes, line heights, and letter spacing perfectly adhere to our design tokens while preventing arbitrary font CSS from leaking into module stylesheets.

### Polymorphic Tag Resolution
To maintain strict accessibility standards and semantic HTML structures without forcing developers to remember token values, the component intelligently maps visual styles to appropriate HTML tags. For example, setting `type="h1"` will automatically render an `<h1>` tag with display font styling, but passing `as="span"` allows you to apply that exact visual style to an inline element if the semantic structure requires it.
