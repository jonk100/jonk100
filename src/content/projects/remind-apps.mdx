## Advanced Frontend Architecture

Building these tools required moving beyond static generation into the realm of complex, stateful web applications. 

### The Tech Stack
* **Supabase:** Provides secure authentication, real-time database subscriptions, and row-level security for user data.
* **XState:** Complex application logic and user flows are modeled using finite state machines, eliminating impossible states and brittle boolean flags.
* **TipTap:** A highly customized, headless rich-text editor allows users to journal with a bespoke writing experience.
* **TypeScript:** End-to-end type safety ensures the data contract between the Supabase backend and the UI components remains unbreakable.

export const habitMachine = setup({
  types: {
    context: {} as { habits: Habit[]; error: string | null },
    events:
      | { type: 'FETCH_HABITS' }
      | { type: 'LOG_HABIT'; id: string }
      | { type: 'RETRY' },
  },
  actions: {
    optimisticUpdate: assign({
      habits: ({ context, event }) => /* update local state immediately */
    })
  }
}).createMachine({
  id: 'habitTracker',
  initial: 'loading',
  states: {
    loading: {
      invoke: { src: 'fetchHabits', onDone: 'idle', onError: 'error' }
    },
    idle: {
      on: { LOG_HABIT: { target: 'syncing', actions: 'optimisticUpdate' } }
    },
    syncing: {
      invoke: { src: 'syncSupabase', onDone: 'idle', onError: 'rollback' }
    },

  }
});

## Engineering Challenges
Integrating a real-time backend with complex local state management required a robust architecture. By leveraging **XState** to orchestrate Supabase mutations alongside local optimistic UI updates, the applications feel instantaneous, hiding network latency from the user entirely.
