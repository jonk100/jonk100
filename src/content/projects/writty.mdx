Writty is a beautiful, minimal, and highly performant personal creative workbench designed to organize, write, and manage creative work across diverse formats—screenplays, songs, poems, and short stories. Leaning into a file-based, local-first workflow, all content lives as version-controlled MDX files inside Astro Content Collections, validated strictly with Zod schemas.

Rather than a public blog or standard CMS, Writty is designed from the ground up as a focused, developer-centric creative writing environment, maximizing speed, design aesthetics, and offline reliability.

## Technical Architecture

Writty utilizes **Astro 6** as its core static engine to pre-render highly structured editorial pages at build-time. It completely skips heavy client-side frameworks, choosing **Alpine.js** for lightweight, reactive frontend widgets (such as character filtering and chord analysis matrices) and **Vanilla CSS** for its elegant, distraction-free typographic design.

## The Screenplay AST Engine

One of the primary engineering challenges in writing screenplays in Markdown is the formatting. Traditional screenplays require rigid alignments: character names centered, parentheticals indented, and dialogue restricted to narrow gutters. Manually wrapping each element in HTML tags or JSX classes makes rapid drafting impossible and breaks the creative flow state.

To solve this, I wrote a custom build-time **Remark plugin** (`remark-screenplay.ts`). This plugin intercepts the Markdown Abstract Syntax Tree (AST) at compile time. It scans the document and transforms a customized shorthand syntax into styled MDX components:

### The Syntax Shorthand
- `s- INT. LENNON'S FLAT - DAY` → Renders a `<Scene>` break
- `c- LENNON` → Renders the `<Character>` speaker anchor
- `p- (grinning)` → Renders dynamic `<Parenthetical>` expressions
- `d- Imagine there's no countries...` → Renders speaker-assigned `<Dialogue>`

### Implicit Formatting Support
To make drafting even faster, the plugin supports **implicit line parsing**:
1. **Implicit Character**: A line written in ALL CAPS (e.g. `LENNON`) is automatically parsed as a `<Character>` block.
2. **Implicit Parenthetical**: A line wrapped in parenthesis `(like this)` within dialogue is treated as a `<Parenthetical>` block.
3. **Implicit Scenes**: A line starting with `INT.`, `EXT.`, or `INT/EXT` is automatically normalized and parsed as a `<Scene>` header.

Here is the recursive AST traversal logic from the parser:

```typescript
// Excerpt from remark-screenplay.ts
export const remarkScreenplay: Plugin<[], Root> = () => {
  return (tree, file) => {
    visit(tree, "paragraph", (node: Paragraph) => {
      const rawText = node.children
        .filter((child): child is Text => child.type === "text")
        .map((child) => child.value)
        .join("");

      // Implicit character line: ALL CAPS name
      if (isImplicitCharacterLine(rawText)) {
        flushDialogue();
        inDialogue = true;
        currentCharacter = rawText.toUpperCase();
        dialogueBuffer.push(jsx("Character", currentCharacter));
        return;
      }

      // Implicit parenthetical inside dialogue
      if (inDialogue && isImplicitParentheticalLine(rawText)) {
        dialogueBuffer.push(
          jsx("Parenthetical", stripOuterParens(rawText), { speaker: currentCharacter })
        );
        return;
      }
      
      // Implicit scene header check
      if (isImplicitSceneLine(rawText)) {
        flushDialogue();
        newChildren.push(jsx("Scene", normalizeSceneHeading(rawText)));
        return;
      }
    });
  };
};
```

This transforms raw Markdown files into a beautifully formatted, standardized screenplay view with an interactive current-line highlighter and a side-by-side editing canvas:

## Mathematical Music Theory & Diatonic Chords

Writty includes a powerful suite of songwriting features designed around **music theory mathematics**.

Under `src/utils/music/musicTheory.ts`, scale and chord structures are modeled as raw semitone offsets from a dynamic root note name. This lets Writty calculate keys, modes, and chord voicings completely on-the-fly:

```typescript
// excerpt from src/utils/music/musicTheory.ts
export const INTERVALS = {
  P1: { name: 'Perfect Unison', shortName: 'R', semitones: 0 },
  m2: { name: 'Minor 2nd', shortName: 'b2', semitones: 1 },
  M2: { name: 'Major 2nd', shortName: '2', semitones: 2 },
  m3: { name: 'Minor 3rd', shortName: 'b3', semitones: 3 },
  M3: { name: 'Major 3rd', shortName: '3', semitones: 4 },
  P4: { name: 'Perfect 4th', shortName: '4', semitones: 5 },
  TT: { name: 'Tritone', shortName: 'b5', semitones: 6 },
  P5: { name: 'Perfect 5th', shortName: '5', semitones: 7 },
  m7: { name: 'Minor 7th', shortName: 'b7', semitones: 10 },
  M7: { name: 'Major 7th', shortName: '7', semitones: 11 },
};

export const CHORD_FORMULAS = [
  { name: 'Major', abbreviation: '', intervals: [0, 4, 7], quality: 'major' },
  { name: 'Minor', abbreviation: 'm', intervals: [0, 3, 7], quality: 'minor' },

```

By querying these vectors, Writty renders interactive fretboard fingerings, translates keys, and maps diatonic chords (e.g. `I, ii, iii, IV...`) to songwriting templates, facilitating creative melody drafting.

## Plot Beat & Tension Visualization

To manage pacing across complex screenplay structures, Writty stores scene descriptions and dynamic **beat arcs**. Using an interactive, custom Alpine.js charting wrapper, Writty plots an episode's emotional tension and pacing curves. This provides visual confirmation of narrative structures (such as rising action, climax, and resolution), helping to identify pacing bottlenecks before starting production drafts.

## Data Enrichment Pipelines

To support secondary collections (like character profiles and film/book reviews), I engineered automated Node.js data pipeline scripts (`enrich-tmdb.ts` and `enrich-actors.ts`).

Running these locally queries the **TMDB API**, extracting cast profiles, actor headshot paths, production details, and aggregate ratings, then merges this data directly back into the MDX frontmatter. This keeps reviews rich, automated, and contextually hyperlinked:

```bash
# Automate review metadata enrichment
pnpm run tmdb
```
